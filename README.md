# Stick Fight — сборка для Vercel

Статический сайт: вся игра — один файл `public/index.html` (шрифты, QR-библиотеки и графика уже внутри). Сборка не нужна.

## Деплой

**Через сайт (проще всего)**
1. Залей эту папку в репозиторий на GitHub.
2. На vercel.com: Add New → Project → выбери репозиторий → Deploy. Настройки менять не нужно: `vercel.json` уже указывает папку `public`.

**Через консоль**
```
npm i -g vercel
cd stick-fight-vercel
vercel --prod
```

## Заметки
- Vercel отдаёт сайт по HTTPS — это нужно для камеры (режим QR) и сетевой игры.
- Режим «Авто» ищет игры через внешние сервисы ntfy.sh и api.ipify.org, своего сервера не требуется. Сама игра идёт напрямую между устройствами (WebRTC).
- Обновить игру: замени `public/index.html` и сделай новый деплой.
